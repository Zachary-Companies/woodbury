# Change Log — 2026-03-18 to 2026-03-19

## Summary

Two-day session spanning NLE editor enhancements, a full Blender-style render pipeline, dialog clip inspector with voice/audio integration, pipeline logo generation, home page app shortcuts, configurable dashboard navigation, website updates with Pipelines showcase, and multiple bug fixes. **9 commits across 12+ files.**

---

## New Features

### NLE Editor — Render Panel
- Blender-style render/output panel added as a sidebar tab ("Render")
- **Format section**: Resolution X/Y, percentage scale dropdown, frame rate selector
- **Frame Range section**: Start/End timecodes (editable), computed duration and frame count, "Full Sequence" and "Use Selection" quick buttons
- **Output section**: Path input with browse button (uses project folder), file format dropdown (MP4 H.264, WebM VP9, ProRes MOV, PNG Sequence), quality presets (Low CRF 28, Medium CRF 23, High CRF 18, Lossless CRF 0)
- **Render section**: "Render Full Sequence" and "Render Range Only" buttons, progress bar with percentage, "Open Output File" button post-render
- Backend: `POST /api/app/:id/render-video` endpoint using ffmpeg to assemble frames + audio into video
- Backend: `POST /api/app/:id/render-cancel` to abort in-progress renders
- Backend: `POST /api/app/:id/open-path` to reveal files in Finder

### NLE Editor — Dialog Clip Inspector
- Clicking a dialog clip in the timeline now shows a detailed inspector panel
- **Speaker section**: Character name and voice assignment status
- **Transcript section**: Full dialogue text displayed in a read-only textarea
- **Audio section**: Status indicator (generated/not generated), play button for existing audio, "Generate Audio" button that calls `POST /api/app/:id/generate-dialogue-audio`
- Fixed voice assignment lookup to use app-level character-to-voice bindings instead of missing `character.voiceId` field

### NLE Editor — App Sidebar Collapse
- Added a thin toggle strip between the pipeline navigation sidebar and the editor content
- Click to collapse/expand the entire left navigation panel
- Smooth CSS transitions, purple hover glow indicator
- State persists during the session via `editorState.appSidebarCollapsed`
- CSS injected into `<head>` via `ensureAppSidebarToggleCSS()` to work outside the scoped view CSS

### Pipeline Logo Generation
- New modal accessible from the pipeline sidebar header
- Prompt field for describing the desired logo
- "Generate" button uses nanobanana (Gemini image model) to create the logo
- Preview displayed in modal before confirming
- Saves to pipeline directory and updates `pipeline.json` metadata with logo path
- Logo displayed in the sidebar header next to the pipeline name

### Home Page — App Cards ("Your Apps")
- New section on the dashboard home page before "What You Can Do"
- Shows all pipelines that have custom views (app UIs) as clickable cards
- Clicking a card navigates directly to the pipeline's app screen
- `GET /api/compositions` response now includes `hasViews` flag

### Configurable Dashboard Navigation
- Right-click the left sidebar to open a visibility menu
- Checkboxes for each navigation tab (Home, Chat, Flows, Pipes, Runs, Train, Store, Social, Assets, Memory, Skills, Boards, Voices, MCP)
- Settings persisted to `localStorage` under `woodbury-nav-tabs`
- Default visible tabs: Home, Chat, Flows, Pipes, Assets, Memory, Voices

### Website — Pipelines Section
- New "Pipelines" section on the landing page between Features and Stats
- Featured card for **Comprehensive Screenplay Generator** with tags, node count, view list, and GitHub link
- "Coming Soon" cards for Social Content Calendar, Brand Asset Generator, and Podcast Producer
- Pipelines link added to navbar, mobile menu, and footer
- Hero subtitle updated to mention creative pipelines
- Deployed to Firebase Hosting

## Bug Fixes

### Clip Selection Stability
- Fixed clip IDs changing on every re-extract (were using `Math.random()`)
- Now uses deterministic IDs based on element content, preventing selection loss on rerender

### Previs Image Display
- Editor was showing old/stale previs images instead of regenerated ones
- Fixed to prefer `_generatedFilePath` from regenerated shots
- Avoids `/tmp/` path overwrites from stale pipeline node outputs

### Voice Assignment in Editor
- "No voice assigned" error appeared even when voices were configured in the Voices tab
- Fixed lookup path: now reads from app-level character-to-voice bindings instead of `character.voiceId`

### Timeline Scrubber CSS
- Scrubber row styles (`.ed-tl-scrubber-row`, etc.) went missing from `view.css`
- Restored all scrubber CSS — horizontal timecode ruler renders properly again

### App Nav Panel Height
- `.app-nav` was using `flex: 1` which made it stretch to fill the sidebar even when internal panels were collapsed
- Changed to `height: auto` so it only takes the space its content needs

### Project Folder Asset Pipeline
- Exposed `projectFolder` on script execution context
- Pipeline scripts now save assets directly to the project folder instead of `/tmp/`
- `dialogAudioMap` entries preserved across re-renders

### Pipeline CTA on Website
- Removed misleading "Pipeline included with install" text
- Updated to "View on GitHub" button linking to the pipeline repo
- Subtitle now says "Clone into ~/.woodbury/workflows/ to install"
